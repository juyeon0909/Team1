## 프로젝트 주제

**잇츠 인 마이 냉장고**

냉장고 재고 기반 맞춤형 레시피 추천 서비스

## 주제 선정 이유

이제 막 자취를 시작한 사회 초년생부터,

몇 년째 요리를 하고 있는 주부까지..

많은 사람들은 맛있는 것을 먹기위해,

또한 어떤 이들은 살기위해서 밥을 먹는다.

그러나 매번 배달음식을 먹기에는 자금도 건강도 위험해지기 때문에 직접 요리를 해먹는 것이 중요한데,

그럴때마다 냉장고는 쓰다 남은 재료,

사놓고 까먹은 재료들로 가득 채워지다가 결국 버려지는 음식들이 너무 많다.

이러한 재료들을 가능한 효율적으로, 많이 사용하여 냉장고 관리를 하기 위한 방법으로 관리 시스템을 도입하고자 한다.

 두번째,  유튜브나 릴스, 쇼츠 등 다양한 플랫폼에서 참신한 레시피들이 무수하게 올라온다. 

시청자들은 이건 해봐야지 하고 저장해둔 레시피가 많지만

어디에 저장했는지, 재료가 있는지 고민하다가 실제로 해먹는 경우는 드물다. 

이러한 고민을 해결하기 위해서 각종 사이트에 퍼져있는 레시피를 취합하고자 한다.

메인 페이지에서 링크를 달아 카드 형식으로 각종 레시피들를 모아서 저장하고,

냉장고에 등록해둔 재료 활용을 극대화하여 

카테고리 별로 편리하게 찾아보고자 하였다.

## 주요 기능

1. 식재료 관리 (우선순위 상)
    - 보관함 등록 : 냉장/냉동/실온으로 구분하여 재료 이름, 수량, 유통기한 입력
    - 간편 삭제
    - 요리가 끝났다면 다 사용한 재료를 선택해서 삭제할 수 있음.
    - 보관함은 유통기한 기준으로 나열함
    - 기간이 얼마 안남은 재료는 배경색이 변함 (3일이내 : 빨강, 7일 이내 : 노랑)
    - 재료는 공공데이터포털 식품영양정보에서 api를 받아 일일이 로컬 DB에 등록
2. 레시피 등록 (우선순위 상)
    - 멀티미디어 참고 : 유튜브, 쇼츠, 릴스 등 최신 트랜드의 영상 레시피를 등록
    - 재료 중요도 세분화 : 각 재료별로 ‘필수’와 ‘선택’을 구분하기
    - 관리자 뿐만 아니라 사용자도 레시피를 올릴 수 있음. 
    단, 관리자에게 승인을 받아야 함.
3. 레시피 선택 (우선순위 상)
    - 페이징 기법 : 한 페이지에 너무 많은 레시피가 뜨지 않도록 설정
    - 간소화 기능 : 카드 형태로 나열된 레시피에는 간단한 소개와 이름, 사진만 보임.
    - 상세 보기 : 레시피를 선택하면 필요한 재료와, 레시피의 주인, 사진, 레시피 링크 등 자세한 정보를 확인할 수 있다.
    - 메인 페이지에서 스크랩이 많은 순으로 정렬 가능
    - 보기 순 정렬 : 추천순, 최신순, 인기순, 리뷰순
4. 매칭 및 필터링 시스템 (우선순위 중)
    - 보관함 연동 : 냉장 / 냉동 / 실온으로 구분된 사용자 인벤토리와 레시피 데이터를 대조함.
    - 일치율 필터 : 50퍼 이상 , 70퍼 이상, 100퍼
    - 카테고리 분류 : 한식, 양식, 일식, 중식, 간식, 야식, 다이어트식, 밀프랩 등 간단하고 다양한 카테고리 필터로 취향에 맞는 메뉴를 선별
    - 레시피를 선택한다면, 내가 가지고 있지 않은 재료를 모아서 알려줌.

5. 스크랩 및 리뷰 기능 (우선순위 하)

  - 리뷰 기능 : 레시피를 이용해 음식을 먹은 사용자가 리뷰를 달 수 있다.
  - 스크랩 기능 : 관심 있는 레시피를 스크랩할 수 있음
  - 정보 관리 : 본인이 쓴 리뷰나 스크랩을 모아서 볼 수 있고, 수정할 수 있다.
6. 부가 편의 기능 (구독 서비스) (우선순위 하)
    - 유통기한 알림(3 일전부터)
    - 부족한 재료 장바구니 리스트
    - 소비기한이 임박된 재료 순서대로 냉장고에 보여준다.
    - 자신의 레시피가 먼저 나오도록 할 수 있다.

## 기대 효과

1. **식재료 낭비 방지** : 구매 후 잊어버려서 유통기한이 지나는 식재료를 최소화하여 경제적, 환경적 이득을 제공
2. **결정 장애 해소** : “오늘 뭐 먹지?”라는 고민에 대해, 현재 가진 재료라는 명확한 가이드라인을 제시해 메뉴 선택 시간을 단축함
3. **스마트 쇼핑** : 부족한 재료를 실시간으로 메모할 수 있어 사용자의 편의성을 높임.
4. **자취생의 식비 절약 및 경제적 효율성 :** 불필요한 중복 구매를 방지하고 냉장고 속 재료를 알뜰하게 소비
5. **건강한 식습관** : 배달 음식 의존도를 낮추고 직접 요리하는 빈도를 높임
6. **사용자 경험 증대** : 단순히 레시피를 검색하는 것을 넘어 ‘내 상황’에 맞는 능동적인 정보를 제공 받는 편리함
7. 1인 가구의 식재료 관리 최적화
8. 메뉴 선택의 스트레스 해소
